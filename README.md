Welcome to the Toy Robot Challenge 🤖

Follow the steps below to run and test the Toy Robot application:

   1- Open the index.html file in your web browser.
  
   2- Open the Developer Console
  
      -Press F12 or Ctrl + Shift + I (Windows/Linux)
      -Press Cmd + Option + I (macOS)
      -N-avigate to the Console tab to view debug output and results.
  
   3- Select the robotcommands file
  
    This will execute all the commands in the file and display the output in the console.
  
   4- Test additional commands
  
      - Edit the existing file to add or modify commands, or
      - Upload your own text file containing custom robot commands.
  
  Feel free to experiment and see how the robot responds to different instructions!
